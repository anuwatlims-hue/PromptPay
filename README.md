# เว็บไซต์แสดงผลงาน ฝ่ายดนตรี กองสวัสดิการ (ดุริยางค์ตำรวจ)

เว็บไซต์แบบ static สำหรับแสดงผลงาน กิจกรรม ภาพนิ่ง และวิดีโอ โดยใช้ข้อมูลจากเพจ
[facebook.com/ThaiPoliceBand](https://www.facebook.com/ThaiPoliceBand/) ไม่มีระบบสั่งซื้อ จองคิว หรือฟอร์มรับข้อมูลใด ๆ

## การใช้งาน

```sh
npm start   # เปิด http://localhost:8080 (ต้องเปิดผ่าน http เพราะหน้าเว็บโหลด data/content.json)
npm test    # ตรวจข้อมูลและฟังก์ชันด้วย node --test (ไม่ต้องติดตั้ง dependency)
```

ไม่มีขั้นตอน build — นำ repository นี้ขึ้น static hosting (เช่น GitHub Pages) ได้ทันที

## การเพิ่มหรือแก้ไขผลงาน

แก้ไข `data/content.json` แล้วรัน `npm test` แต่ละรายการใน `items` มีรูปแบบดังนี้

| ฟิลด์ | คำอธิบาย |
| --- | --- |
| `id` | รหัสไม่ซ้ำกัน |
| `type` | `video`, `photo` (อัลบั้มภาพ) หรือ `post` |
| `title`, `text` | หัวข้อและข้อความของโพสต์ |
| `category` | คีย์จาก `categories` (`concert`, `activity`, `news`) |
| `date` | วันเวลาแบบ ISO เช่น `2026-10-21T19:00:00+07:00` |
| `url` | ลิงก์โพสต์บน Facebook |
| `videoUrl`, `durationSeconds`, `orientation` | เฉพาะ `video` — ลิงก์วิดีโอ ความยาว และ `landscape`/`portrait` |
| `sharedFrom` | (ไม่บังคับ) ชื่อเพจต้นทางเมื่อเป็นโพสต์ที่แชร์มา |
| `images` | (ไม่บังคับ) รูปที่เก็บในเว็บ เช่น `[{ "src": "media/concert/01.webp", "alt": "คำบรรยายภาพ" }]` |
| `poster` | (ไม่บังคับ) ภาพปกของวิดีโอ เช่น `media/concert/cover.webp` |

## การแสดงภาพและวิดีโอ

- **วิดีโอ** เล่นผ่านปลั๊กอินฝัง (embed) ทางการของ Facebook และโหลดเมื่อผู้ใช้กดเล่นเท่านั้น หน้าเว็บจึงโหลดเร็ว
- **ภาพนิ่ง** มีสองแบบ
  - รายการที่มี `images` แสดงเป็นแกลเลอรีของเว็บเอง (ปัดหรือกดปุ่มเพื่อดูทีละภาพ และใช้ภาพแรกเป็นปก)
    ให้วางไฟล์รูปไว้ในโฟลเดอร์ `media/` แล้วเพิ่มพาธลงใน `data/content.json`
  - รายการที่ยังไม่มี `images` แสดงโพสต์อัลบั้มผ่าน embed ของ Facebook แทน
- โพสต์ต้องตั้งค่าเป็นสาธารณะจึงจะฝังได้ ทุกรายการมีปุ่ม “เปิดบน Facebook” สำรองไว้ในกรณีที่เบราว์เซอร์บล็อกเนื้อหาจาก Facebook
